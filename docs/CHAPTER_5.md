# CHAPTER 5
## CONCLUSION AND RECOMMENDATIONS

### Conclusion
The project successfully developed **"EduTrack PHS: School Learning Resources Inventory and Borrowing Management System with Return Verification,"** a mobile application that provides high schools with an efficient and modern solution for managing educational resources. All major requirements and specific objectives were implemented and tested successfully.

The application enables students, teachers, property custodians, and school administrators to access inventory records, borrow equipment quickly using QR code scanning, enforce section-based borrowing limits to share resources fairly, and verify return conditions using photo proof. By replacing manual logbooks and paper slips with a cloud-connected mobile platform powered by Flutter and Google Firebase, the system significantly improves equipment tracking, minimizes lost or uninspected items, and strengthens accountability across the school. Through this project, the team demonstrated the practical application of mobile development concepts, cloud database design, and user interface principles.

---

### Recommendations
To further enhance and expand the capabilities of EduTrack PHS in future iterations, the following improvements are recommended:

1. **Implement Push Notifications via Firebase Cloud Messaging (FCM):** Send background push alerts to borrowers for upcoming due dates, overdue reminders, and return status updates even when the application is closed.
2. **Develop an iOS and Web Dashboard Version:** Expand platform availability to iOS devices and create a web-based dashboard for school administrators and property custodians who prefer desktop management.
3. **Add Offline Mode and Local Caching:** Integrate local database caching to allow users to view previously loaded inventory items and queue transactions temporarily during intermittent internet connections.
4. **Integrate AI Image Damage Detection:** Explore machine learning image recognition models to automatically detect visible cracks, tears, or defects in uploaded return photos before manual custodian review.
5. **Support RFID and NFC Tagging:** Integrate contactless RFID or NFC hardware scanning for instant multi-item checkouts in science laboratories and TVL workshops.
